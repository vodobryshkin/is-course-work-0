## Use Case диаграммы
Use Case диаграммы были написаны в формате PlantUML. Код всех диаграмм можно найти в [файле](https://github.com/vodobryshkin/is-course-work-0/blob/1128891e6a1811a84ce62a656e1f50aaaac810f7/use-cases/us.puml).

Для компиляции диаграмм пропишите в терминале:
```shell
cd use-cases
java -jar plantuml-1.2026.8.jar -tpng us.puml
```
