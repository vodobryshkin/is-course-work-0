# Информационная система скаутинга и трансферов футбольного клуба.

## 2. Составить подробное текстовое описание предметной области.
Предметная область связана с поиском и оценкой футболистов для футбольного клуба. Поиском игроков занимаются скауты, 
которые просматривают матчи, изучают статистику и составляют отчёты по интересующим футболистам. Для каждого игрока 
могут учитываться его позиция, возраст, текущий клуб, срок действия контракта, основные игровые показатели и оценки 
скаутов. Один и тот же футболист может просматриваться несколько раз разными скаутами, поэтому по нему может 
накапливаться несколько отчётов и оценок.

После просмотра подходящие игроки могут быть добавлены в список кандидатов на трансфер. Решение о дальнейшей работе с 
кандидатом принимается тренерским штабом и спортивным директором. Если клуб заинтересован в переходе футболиста, 
начинается работа по трансферу: ведутся переговоры с текущим клубом игрока и его представителем, обсуждаются сумма 
перехода и условия контракта. Трансфер может завершиться переходом футболиста, отказом одной из сторон или прекращением 
переговоров. Таким образом, предметная область включает футболистов, скаутские отчёты, списки кандидатов, трансферные 
предложения и состояние переговоров по каждому игроку.

## 3. Сформулировать, зачем нужна информационная система для представленной предметной области, какие задачи она позволит решить.

Информационная система нужна для хранения данных о футболистах, скаутских отчётах и трансферах в одном месте. При работе
без общей системы информация может храниться в таблицах, документах и переписках, из-за чего сложнее просматривать историю
работы по игроку и понимать его текущее состояние как кандидата на трансфер.

Основные задачи системы:

- централизовать данные о футболистах и скаутских отчётах
- хранить историю просмотров и оценок игроков
- упростить поиск футболистов по основным параметрам
- вести списки кандидатов на трансфер
- распределять задания на просмотр игроков между скаутами
- хранить информацию о ходе трансферных переговоров
- сохранять историю предложений и изменения статуса трансфера
- предоставить тренерам и спортивному директору актуальную информацию по интересующим игрокам

## 4. Составить функциональные/нефункциональные требования к разрабатываемой информационной системе.

| ID  | Название                                | Описание                                                                                                                                                       | Приоритет |
|-----|-----------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------|
| SF1 | Регистрация и авторизация пользователей | Система предоставляет пользователям возможность зарегистрироваться, войти в систему и получать доступ к функциям в зависимости от своей роли.                  | MUST      |
| SF2 | База футболистов                        | Система хранит информацию о футболистах, включая основные данные, игровую позицию, текущий клуб, срок действия контракта и данные, используемые при скаутинге. | MUST      |
| SF3 | Скаутские отчёты                        | Система позволяет скаутам создавать отчёты по футболистам, выставлять оценки и сохранять результаты просмотров.                                                | MUST      |
| SF4 | Поиск и отбор футболистов               | Система позволяет искать футболистов по заданным параметрам и добавлять подходящих игроков в списки кандидатов.                                                | MUST      |
| SF5 | Скаутские задания                       | Система позволяет назначать скаутам задания на просмотр определённых футболистов и отслеживать состояние их выполнения.                                        | SHOULD    |
| SF6 | Ведение трансферов                      | Система хранит информацию о переговорах по футболисту, предложениях сторон, текущем статусе трансфера и результате переговоров.                                | MUST      |
| SF7 | Администрирование                       | Система предоставляет возможность управлять пользователями и контролировать доступ к данным и функциям системы.                                                | COULD     |
